نسخة المشروع الكاملة المعتمدة - مع الشعار
========================================
هذه هي النسخة التي اعتمدتها: فيها الشعار، المواد الكاملة 1-12، الصفحة الرئيسية، نسخ ولصق فقط، الحفظ والتقارير، التقرير صفحتين، التوقيعات + التاريخ التلقائي.
تعديل واحد فقط: سطر الحقوق لا يظهر في الطباعة (تم إزالته من التقرير المطبوع، ويظهر فقط بأسفل التطبيق على الشاشة).

الملفات:
- src/App.tsx : التطبيق كامل
- src/index.css : التنسيقات
- logo.png / src/logo.png : شعار وزارة التربية والتعليم
- package.json + vite.config.ts + index.html : ملفات البناء

للرفع على Cloudflare Pages عبر GitHub:
1. ارفع كل الملفات في هذا المجلد على مستودع GitHub tahlil (احذف الملفات القديمة أولاً)
2. في Cloudflare Pages > Import from Git > اختر tahlil
3. Project name: tahlil-nataij
4. Framework preset: Vite
5. Build command: npm run build
6. Output directory: dist
7. Save and Deploy
